# Android app

*Part of [packaging](../README.md). To install and use it, see the [installation guide](../../docs/install.md#android).*

A standalone Android app: a thin shell around the same Python server that runs on the computer. A foreground service starts the
server using Python 3.12 and ffmpeg built for Android (the [youtubedl-android](https://github.com/yausername/youtubedl-android)
project), and a WebView shows the page from `http://127.0.0.1:8765`. Nothing leaves the phone except the requests to YouTube.

## Build

```
packaging\android\build.bat
```

Needs **JDK 21** (JDK 17 on very recent Windows 11 has a local-network defect and Gradle does not start), the **Android SDK**
(platform 34, build-tools 34.0.0) and **Gradle 8.7**, by default in `C:\AndroidBuild\` (change it with the `ANDROID_BUILD_ROOT`
environment variable). The script runs Gradle without a daemon, in a single process, for the same reason.

The APKs (`arm64-v8a`, `armeabi-v7a`, `x86_64`) go to `dist\android\`. The build copies the files of `program\` into the APK at every
run. To bundle a newer yt-dlp, delete `app\src\main\assets\ytg-libs.zip` before building (it is regenerated by `tools\make_libs.py`).

## The signing key

The APK is signed with the key in `packaging\android\keystore\` (`ytgrabber.jks` plus `keystore.properties` with its password).
**Keep a safe copy of it outside the repository**: the same key is needed to install updates over the version already installed;
with another key Android makes you uninstall the app (and lose its data) first. The folder is ignored by git. If it is missing,
`build.bat` creates a new key with a random password.

## What is in this folder

| Path | What it is |
|---|---|
| `build.bat` | the build script (the APKs go to `..\..\dist\android\`) |
| `app\` | the Android app: Kotlin sources in `src\main\java`, resources (`values-<lang>\strings.xml` in 16 languages), manifest |
| `tools\make_libs.py` | prepares the bundled Python packages (`ytg-libs.zip`) |
| `keystore\` | the signing key (secret, not in git) |
| `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties` | the Gradle configuration (`versionName` and `versionCode` are set by `tools/bump_version.py`) |
