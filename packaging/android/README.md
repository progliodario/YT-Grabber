# Android application

*Part of [packaging](../README.md). For installation and use, see the [installation guide](../../docs/install.md#android).*

A standalone Android application: a thin shell around the same Python server that runs on the computer. A foreground service starts
the server using Python 3.12 and ffmpeg built for Android (the [youtubedl-android](https://github.com/yausername/youtubedl-android)
project), and a WebView displays the page from `http://127.0.0.1:8765`. Nothing leaves the phone except the requests to YouTube.
The service also posts the notification of a finished download, by polling the local server.

## Build

```
packaging\android\build.bat
```

The build requires **JDK 21** (JDK 17 on very recent versions of Windows 11 has a local-network defect that prevents Gradle from
starting), the **Android SDK** (platform 37.0, build-tools 36.0.0) and **Gradle 9.6.0**, located by default in `C:\AndroidBuild\`
(this can be changed with the `ANDROID_BUILD_ROOT` environment variable). For the same reason, the script runs Gradle without a
daemon, in a single process; the memory settings are therefore given identically in `GRADLE_OPTS` (in `build.bat`) and in
`org.gradle.jvmargs` (in `gradle.properties`), so that Gradle does not start a second process. The project uses the Android Gradle
plugin 9.5 with its built-in Kotlin support, and the same build runs in CI (job *Android app builds*) without the signing key.

The APKs (`arm64-v8a`, `armeabi-v7a`, `x86_64`) are placed in `dist\android\`. At every run, the build copies the files of `program\`
into the APK. To bundle a newer yt-dlp, delete `app\src\main\assets\ytg-libs.zip` before building (it is regenerated by
`tools\make_libs.py`).

## The signing key

The APK is signed with the key in `packaging\android\keystore\` (`ytgrabber.jks` and `keystore.properties`, which contains its
password). **A safe copy must be kept outside the repository.** The same key is required to install updates over the version that is
already installed; with a different key, Android requires the application to be uninstalled first, and its data is lost. The folder
is ignored by git. If it is missing, `build.bat` creates a new key with a random password.

## Contents of this folder

| Path | Description |
|---|---|
| `build.bat` | the build script (the APKs are placed in `..\..\dist\android\`) |
| `app\` | the Android application: Kotlin sources in `src\main\java`, resources (`values-<lang>\strings.xml` in 16 languages), manifest |
| `tools\make_libs.py` | prepares the bundled Python packages (`ytg-libs.zip`) |
| `keystore\` | the signing key (secret, not in git) |
| `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties` | the Gradle configuration (`versionName` and `versionCode` are set by `tools/bump_version.py`) |
